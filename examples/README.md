# JSango Reference Examples

This directory contains official reference applications demonstrating real-world patterns and best practices using the **JSango** framework.

### Available Examples:

1. **[Enterprise Showcase](enterprise-showcase/) (`example-enterprise-showcase`)**:
   - Comprehensive, production-grade application demonstrating ORM models (`User`, `Product`, `Order`), relationships, in-memory caching (`@jsango/cache`), background job queue workers (`@jsango/queue`), typed event bus (`@jsango/events`), REST APIs, and the **JSango Admin Console** (`@jsango/admin-ui`, `@jsango/admin-server`, `@jsango/admin-core`).
2. **[Basic App](basic-app/) (`example-basic-app`)**:
   - Minimalist getting-started template demonstrating core routing, simple models, and migrations.
3. **[Auth Demo](auth-demo/) (`example-auth-demo`)**:
   - Authentication strategies, role-based access control policies, and secure sessions.
