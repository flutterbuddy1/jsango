# JSango Reference Examples

This directory contains official reference applications demonstrating real-world patterns and best practices using the **JSango** framework.

### Available Examples:

1. **[Basic AI App](basic-ai-app/) (`example-basic-ai-app`)**:
   - Single-file batteries-included starter (`src/index.ts`) showcasing autonomous AI Agent with Tools, Ollama & OpenRouter providers, In-Memory DB & Models, auto-CRUD, React Admin UI, OpenAPI documentation, and typed events & background jobs.

2. **[Voice Agent](voice-agent/) (`example-voice-agent`)**:
   - A support agent you can talk to in the browser, over WebRTC or on a phone call (Twilio), with any LLM and any speech-to-text / text-to-speech chosen from `.env` (OpenAI, Anthropic, Ollama, Deepgram, Cartesia, ElevenLabs, Gemini Live, or self-hosted models). Tools, memory, interruptions, and usage / cost / latency / transcripts in the admin. Tested end to end with fake models.
