# @django-js/cli

> CLI runner and developer tooling for project scaffolding, database migrations, inspection, and background workers.

Part of the **[django-js](https://github.com/django-js/django-js)** backend framework for TypeScript.

## Installation

```bash
pnpm add @django-js/cli
```

## Usage

```typescript
# Scaffolding a new project
npx django-js create my-app

# Running migrations
npx django-js migrate:run

# Inspecting routes & models
npx django-js route:list
npx django-js model:list
```
