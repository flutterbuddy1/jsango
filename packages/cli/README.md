# @jsango/cli

> CLI runner and developer tooling for project scaffolding, database migrations, inspection, and background workers.

Part of the **[jsango](https://github.com/flutterbuddy1/jsango)** backend framework for TypeScript.

## Installation

```bash
pnpm add @jsango/cli
```

## Usage

```bash
# Scaffolding a new project
npx @jsango/cli create my-app

# Running migrations
npx @jsango/cli migrate:run

# Inspecting routes & models
npx @jsango/cli route:list
npx @jsango/cli model:list
```
