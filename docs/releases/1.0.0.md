## Welcome to jsango 1.0.0

`jsango` is a production-grade, batteries-included TypeScript backend framework designed from first principles for modern JavaScript runtimes. It unites the developer ergonomics and convention-over-configuration philosophy of Django with strict compile-time type safety, modular packages, and high-concurrency execution.

---

## Key Highlights of 1.0.0

### 1. High-Performance Architecture

- **Radix Trie Routing**: Over **7.7M operations/sec** static route lookups with $O(1)$ fast-path execution.
- **Dependency Injection**: Microbenchmark-proven DI resolution at **24.1M ops/sec** across transient, singleton, and scoped lifetimes.
- **Zero Memory Leaks**: Validated against 5,000 continuous request cycles, 5,000 DI scopes, and 1,000 concurrent WebSocket room transitions.

### 2. Full-Featured Batteries Included

- **Runtime & Core**: Node.js 20+ runtime adapter with lifecycle coordination and structured errors.
- **HTTP Engine**: Runtime-independent request/response abstractions, streaming parsers, and cookie security.
- **Database & ORM**: Connection pooling, transaction savepoints, model dirty tracking, and zero N+1 batch eager loading (`.with()`).
- **Schema Migrations**: Live database reflection, topological schema diffing, and distributed concurrency locking.
- **Authentication & Authorization**: Scrypt password hashing, JWT/Session/API Key strategies, and object-level policy engine.
- **Cache & Queue**: Driver-agnostic caching with stampede locks (`remember`) and at-least-once background job workers.
- **Events & WebSockets**: Tri-mode event bus (`sync`, `async`, `queued`) and multi-room WebSocket management with heartbeat monitoring.
- **Admin Platform**: Model-driven resource definitions, CRUD REST API server, staff RBAC, and immutable audit logs.
- **OpenAPI 3.1 & Observability**: Deterministic document generation, Prometheus metrics, structured JSON logging, and monotonic tracing.

## Quick Start

```bash
# Scaffold a new 1.0 application
npx jsango create my-app
cd my-app
pnpm install
pnpm build
pnpm start
```
